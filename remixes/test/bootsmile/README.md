# bootsmile (test remix)

BOOT SMILE alone, with the stock effects: at power-on a white smile on black grows, stays and
melts, in place of the Elektron logo. It is meant for the owner's acidtrack remix; this test remix
carries it so its gate runs.

The first build ran on the owner's MKI on 24 Oct 2026 (it showed black on white; the frames are
inverted since). Gate: `tools/bootsmile/test_bootsmile.py` (the source under cfsim).
