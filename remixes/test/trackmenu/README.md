# trackmenu (test remix)

TRACK MENU v2 beside OCTA303, MORPH and STORE, with the stock effects. Hold a track key about a second:
that track's menu opens (a chooser, then the function's page): MORPH (its own settings, armed and
started by the track key), EUKLE (prints, undoes, LIVE) and ERGOSUM. MORPH's own [TRACK]+[UP] window is
unchanged.

v0 navigated on the owner's MKI; v2 not yet on the unit. Gates: `tools/trackmenu/test_trackmenu.py`
and `tools/trackmenu/test_eukle.py` (the sources under cfsim).
