# morph (test remix)

MORPH alone with the stock effects, for its gates: `tools/morph/test_morph.py` runs `morph.s` from
its source text; `tools/morph/port_morph.py` builds this remix, boots it under the port with a
project (`OT_PROJECT`), presses [T1]+[UP] and [T1]+[DOWN] and reads the per-track weights.
