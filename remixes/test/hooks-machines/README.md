# hooks-machines (test remix)

ANALOG BD and OCTA303 in one image: HOOKS gives the track's machine list seven rows, ANALOG BD on row 5 and OCTA-303 on row 6, and the list scrolls. See [HOOKS](../../../modules/hooks/README.md) (`machine_rows`).

`tools/verify/verify_hooks.py hooks-machines` checks the bridged sites in this image after
`make bus REMIX=hooks-machines`.

## Where it has run

Not flashed. Built, and its sites checked (verify_hooks).
