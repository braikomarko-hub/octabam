# `db666-meter` — dB666 with LOAD METER

`stock-meter-b`'s image (the core modules, LOAD METER, the stock effects but
SPATIALIZER, whose words hold the meter's DSP half) with dB666 on its own id
in PLATE REV's words. The image for reading dB666's slot cost on a unit with
`tools/hw/ot_matrix.py` (`docs/contributing/HARDWARE_TESTING.md`): layouts
`DB666 FX1/FX2 def` and `dear` against BASE, and COMPRESSOR beside it as a
check of the rig against the catalog (2.18 % a slot). Its BASE against
`stock-meter-b`'s (22.4 / 14.9 %) carries the side-chain tap asleep.

`make check REMIX=test/db666-meter`.
