# hooks-chrom-303 (test remix)

OCTA303 (the OCTA-303 machine) beside SCALE QUANTIZER: HOOKS gives a 303 track's CHROMATIC keys to OCTA303 and every other track's to SCALE QUANTIZER. See [HOOKS](../../../modules/hooks/README.md) (`chrom_pitch`, `chromatic`).

`tools/verify/verify_hooks.py hooks-chrom-303` checks the bridged sites in this image after
`make bus REMIX=hooks-chrom-303`.

## Where it has run

Not flashed. Built, and its sites checked (verify_hooks).
