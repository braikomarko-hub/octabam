
The **UREI 1176LN** FET limiting amplifier (1967), modelled from its manual:
a FET gain cell in a feedback loop, a fixed threshold you drive into with
INPUT, the four ratio buttons and ALL BUTTONS IN, attack from 20 µs and a
two-capacitor release that lets short peaks go fast and held limiting go
slowly.

## Controls

| Page | Knob | What it does |
|---|---|---|
| 1 | INPT | input, −30 … +30 dB: more input, more limiting |
| 1 | OUTP | output, −30 … +30 dB |
| 1 | ATK | attack, 800 µs (1) … 20 µs (127); 0 = OFF |
| 1 | REL | release, 1.1 s (0) … 50 ms (127) |
| 1 | RATI | 4:1, 8:1, 12:1, 20:1, ALL |
| 1 | MIX | dry/wet; 0 = exact passthrough |
| 2 | REV | LN or BLUE (more 2nd harmonic) |
