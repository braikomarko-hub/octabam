A system module: it adds no screen or control of its own. Modules that keep a
setting in a Part (MIDI LOOPBACK's routing today) read and write it through PARTS,
which keeps the working Part, the battery-backed copy and the save marks in step,
and keeps their reads whole while a Part is being reloaded, pasted or cleared.
Select it with any module that names it as a requirement.

It replaces MIDI PART STATE, whose behaviour it keeps.
