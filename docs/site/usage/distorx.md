Two pedals in one insert: the **BOSS SD-1** Super OverDrive and the **Pro Co
RAT**, with the Turbo RAT as a third mode. MODE picks the pedal; changing it
fades to the dry signal and back in about 3 ms, so a scene or a p-lock can
switch pedals without a click. MODE starts at OFF, so it can be put on a
track in the middle of a set. Built for a TB-303 line, fine on anything.

## Controls

| Knob | What it does |
|---|---|
| LEVL | output level |
| TONE | the pedal's tone control |
| DRIV | drive / distortion |
| IN | input gain into the pedal |
| MIX | dry/wet; 0 = exact passthrough |
| MODE | OFF, SD-1, RAT, TURB |
